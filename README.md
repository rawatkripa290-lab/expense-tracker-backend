# Expense Tracker

A full-stack Expense Tracker application that helps users manage their daily expenses, track spending habits, and organize financial records efficiently.

---

## 🚀 Features

* Add, edit, and delete expenses
* Categorize expenses
* Track total spending
* Responsive user interface
* Real-time updates
* Secure backend API integration
* User-friendly dashboard

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Talwind CSS

### Backend

* Java Springboot

### Database

* MySQL

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/expense-tracker.git
cd expense-tracker
```

---

## ▶️ Frontend Setup

```bash
cd frontend
npm install
npm start
```

Frontend runs on:

```bash
http://localhost:3000
```

---

## ▶️ Backend Setup

```bash
cd backend
npm install
npm run dev
```

Backend runs on:

```bash
http://localhost:5000
```

---

## 🔐 Environment Variables

Create a `.env` file inside the backend folder and add:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
