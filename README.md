💰 Expense Tracker Application
📌 Overview

A full-stack Expense Tracker web application that helps users manage income and expenses efficiently. It provides a simple and responsive interface to track financial activities and view categorized summaries.

🚀 Features
Add income and expense transactions
Edit and delete transactions
View total balance, income, and expenses
Categorized expense tracking
Responsive UI for all devices
REST API integration between frontend and backend
🛠️ Tech Stack

Frontend:

React.js
HTML, CSS, JavaScript

Backend:

Java
Spring Boot
REST APIs

Database:

MySQL
